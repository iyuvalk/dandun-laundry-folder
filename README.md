# dandun-laundry-folder

This repo contains the code for a laundry (currently only short sleeves T-Shirts) folding robot. 

We started this project in Arduino but decided to move to Raspberry Pi before completing the Arduino version so the Arduino is still in WIP stage. All of the materials related are in the `Arduino_Option-WIP` folder.
The materials for the Raspberry Pi version is in the `RaspberryPi_Option_Option` folder.

Good Luck!
